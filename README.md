# Ancient Venice Interactive Tour

Interactive historical and archaeological guide for the WPI Venice Project Center. The Home page introduces the guide and opens a dismissible **Today in Venice History** popup with one randomly selected event for the current date. The **Data** page brings the guide's datasets together, including a timeline of all 1,092 dated history events. Search records, filter by collection, and use the year histogram's draggable minimum and maximum handles (or enter years directly) to narrow the results. Open a record in a centered detail view with concise exhibit-style information and expandable research details. Choose 1–5 landmarks for a walking route, optionally start at your current location, and choose collections to prioritize matching landmarks and show related nearby finds: Venetian Churches, Confraternities & Guilds, Doges & Dynasties, Inscriptions & Street Altars, and Tassini Heritage. Combined **Interests & nearby finds** preferences include optional minimum and maximum built/founded years for route stops and nearby discoveries; route choices outside the selected range are hidden and removed from the current selection when the range changes. Anchor landmarks remain available regardless of the selected year range, and the Data catalog is not affected by these route preference filters. Routes can include ferry connections, which can be turned off to exclude landmarks on boat-served islands; ferry travel duration is an estimate, and the ACTV timetable link provides official departures for the selected travel date and boarding stop. Export the site dataset as GeoJSON. A one-stop route requires the current-location start option.

The Data catalog includes records from `data/venetian_churches.csv`, `data/venetian_confraternities_guilds.csv`, `data/venetian_doges_dynasties.csv`, `data/venetian_inscriptions.csv`, and `data/venetian_tassini_heritage.csv`. The server exposes normalized records at `GET /api/inscriptions` and `GET /api/tassini-heritage`, preserving Tassini citations, quotations, and translations. The Venice history data is available as a full timeline at `GET /api/venice-history-timeline` and as current-date entries at `GET /api/today-in-venice-history?date=MM-DD`. Browse the collections on **Data**, or enable **Venetian Churches**, **Confraternities & Guilds**, **Doges & Dynasties**, **Inscriptions & Street Altars**, or **Tassini Heritage** under Route Builder **Interests & nearby finds** to see nearby records in **Near Me (GPS)**. Click a nearby location or map marker to view its facts and source details; the Tassini collection includes its exact quotation, citation, and English toponymic analysis. Use the corresponding map toggles to show all points in each collection.

## Run locally

Requires Python 3.9 or newer; there are no Python packages to install.

1. Open a terminal in this folder.
2. Run `python server.py` (on Windows, `py server.py` also works).
3. Visit `http://127.0.0.1:8000`.

If the server reports that port 8000 is already in use, stop the other server with **Ctrl+C** in its terminal or use the browser tab that is already open.
